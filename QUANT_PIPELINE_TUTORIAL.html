Step 2 Calculate Asset Percentage Returns

How much did each coin change from one timestamp to the next?

The Exact Formula:
$$\text{Return}_t = \frac{\text{Price}_t - \text{Price}_{t-1}}{\mathbf{\text{Price}_{t-1}}} \quad \text{(Always divide by the PREVIOUS price!)}$$

Let's do the math by hand from T1 to T2:

  • BTC: $(110 - 100) / 100 = 10 / 100 = \mathbf{+0.10 \ (+10\%)}$
  • ETH: $(50 - 50) / 50 = 0 / 50 = \mathbf{0.00 \ (0\%)}$
  • SOL: $(9 - 10) / 10 = -1 / 10 = \mathbf{-0.10 \ (-10\%)}$

returns = (prices - prices.shift(1)) / prices.shift(1)
returns = returns.dropna()

Step 3 The Core Quant Secret: Dollar-Neutral Weights

How do we turn those returns into real hedge fund positions? We use the 3-step Rank → Demean → Normalize engine.

Pen & Paper Walkthrough at Timestamp T2:

At T2, returns were: SOL = -0.10, ETH = 0.00, BTC = +0.10.

  1. RANK from lowest to highest:
    • SOL is the worst (-10%) → Rank 1
    • ETH is in the middle (0%) → Rank 2
    • BTC is the best (+10%) → Rank 3
  2. DEMEAN (Subtract the average rank of 2.0):
    • SOL: $1 - 2 = \mathbf{-1.0}$
    • ETH: $2 - 2 = \mathbf{0.0}$
    • BTC: $3 - 2 = \mathbf{+1.0}$
    Notice: $-1.0 + 0.0 + 1.0 = \mathbf{0.0}$ (Guarantees Dollar-Neutrality: $\sum w_i = 0$).
  3. NORMALIZE (Divide by the sum of absolute values):
    • Sum of absolute values: $|-1| + |0| + |+1| = \mathbf{2.0}$
    • SOL Weight: $-1.0 / 2.0 = \mathbf{-0.50}$ (Short $0.50 of SOL)
    • ETH Weight: $0.0 / 2.0 = \mathbf{0.00}$ (No position)
    • BTC Weight: $+1.0 / 2.0 = \mathbf{+0.50}$ (Long $0.50 of BTC)
    Notice: $|-0.50| + |0.00| + |+0.50| = \mathbf{1.0}$ (Guarantees Unit Gross Leverage: $\sum |w_i| = 1.0$).
Timestamp BTC Weight ETH Weight SOL Weight Sum of Weights (Net Market Exposure) Sum of Abs Weights (Gross Leverage)
T2 +0.50 (Long) 0.00 -0.50 (Short) 0.00 (Dollar-Neutral!) 1.00 (1x Leverage)
T3 -0.50 (Short) 0.00 +0.50 (Long) 0.00 (Dollar-Neutral!) 1.00 (1x Leverage)
Python Code:
ranks = current_signal.rank()
centered_ranks = ranks - ranks.mean()
weights = centered_ranks / centered_ranks.abs().sum()

Step 4 Calculate Strategy Returns (Did the bets make money?)

Now, how much did our portfolio actually make or lose? We must simulate holding the portfolio into the future.

Crucial Rule: Prevent Look-Ahead Bias!

At T2, you made your decision: Long BTC (+0.50), Short SOL (-0.50). You hold this position from T2 to T3.
Therefore, your return at T3 is: $$\text{Strategy Return at T3} = \mathbf{w}_{\text{T2}} \times \mathbf{R}_{\text{T3}}$$ That is why in code we write: previous_weights = weights.shift(1)!

Pen & Paper P&L at Timestamp T3:

Positions decided at T2: BTC = +0.50, SOL = -0.50.

Actual returns that happened between T2 and T3: BTC = -5.0%, SOL = +10.0%.

  • BTC P&L: $+0.50 \times (-0.05) = \mathbf{-0.025 \ (-2.5\%)}$
  • ETH P&L: $0.00 \times (+0.05) = \mathbf{0.000}$
  • SOL P&L: $-0.50 \times (+0.10) = \mathbf{-0.050 \ (-5.0\%)}$
  • Total Portfolio Return at T3: $-0.025 + 0.00 - 0.050 = \mathbf{-0.075 \ (-7.5\%)}$!

Why did Momentum lose -7.5%? Because the T2 winner (BTC) crashed -5%, and the T2 loser (SOL) rebounded +10%!

Python Code:
previous_weights = weights.shift(1)
strategy_returns = (previous_weights * returns).sum(axis=1)

Step 5 The Final Scorecard: The Sharpe Ratio

Now that we have our timeline of strategy returns, we compute the final score:

The Sharpe Formula:
$$\text{Sharpe Ratio} = \frac{\text{Average Return}}{\text{Volatility (Risk)}} \times \sqrt{\text{Annualization Factor}}$$
